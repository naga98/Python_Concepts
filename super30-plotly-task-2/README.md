# Plotly Visualization Challenge

This project implements the Plotly Visualization Challenge. It converts small, meaningful datasets into interactive HTML charts.

## Requirements

- Python 3.9 or newer
- NumPy
- Plotly

Install dependencies:

```bash
py -m pip install numpy plotly
```

The solution was tested with Plotly 7.1.0.

## Run

From this folder:

```bash
py plotly_visualizations.py
```

The script creates an `output` folder containing 12 interactive HTML files. Open any HTML file in a browser to zoom, hover over values, pan, and toggle legend entries.

## Charts included

1. **Bar chart:** monthly sales from January through June.
2. **Line chart:** the same monthly sales, showing the trend over time.
3. **Pie chart:** employee distribution across Engineering, Sales, Marketing, HR, and Operations.
4. **Scatter plot:** the relationship between hours studied and exam marks for 15 students.
5. **Histogram:** the distribution of 500 normally distributed random values.
6. **Box plot:** salary spread for 30 employees, including the mean marker.
7. **Multiple categories:** grouped monthly sales for Laptop, Mobile, and Tablet.
8. **Student performance:** grouped Python, Mathematics, and Data Science marks for 10 students.
9. **3D scatter plot:** 30 employees represented by age, salary, and experience.
10. **Custom graph:** website visitors grouped by acquisition channel.
11. **NumPy + Plotly:** 100 random integers generated by NumPy and plotted as a line chart.
12. **Dashboard:** four business charts for revenue, expenses, employees, and customers.

Every chart has a descriptive title. Charts with axes have axis labels, and charts with multiple series include a legend.

## Important Plotly ideas

### Figure and trace

A Plotly `Figure` contains one or more traces. A trace is a data series, such as a bar series or a line series.

```python
figure = go.Figure(go.Bar(x=months, y=sales, name="Sales"))
```

### Interactivity

`write_html()` saves the figure with Plotly's browser-based interactions. The generated charts support hover tooltips, zooming, panning, selection, and legend toggling.

### Reproducible random data

The script uses:

```python
rng = np.random.default_rng(42)
```

The fixed seed means the histogram, NumPy chart, and random matrix-related data are repeatable across runs.

### Chart selection

- Bar charts compare separate categories.
- Line charts show change across an ordered sequence such as months.
- Pie charts show parts of a whole.
- Scatter plots show relationships between two numerical variables.
- Histograms show frequency distribution.
- Box plots summarize spread, median, quartiles, and possible outliers.
- 3D scatter plots show relationships among three numerical variables.
